# Page Turners Analysis
This project explores the popularity and the ranking of books within the Goodreads-10k dataset. The following analysis is focused on four research questions:
- Is there a relationship between a book's popularity and its average rating?
- Are older books rated differently from recently published books?
- Which genres tend to receive the highest average ratings?
- How are Goodreads user ratings distributed?

The project will use Python and libraries such as pandas, NumPy, SciPy, and Matplotlib for data cleaning, statistical analysis, and visualization. The results will be presented through an interactive Streamlit application.
